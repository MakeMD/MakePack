# MakePack

Легкий архіватор для Windows 10/11 — Zig + Dear ImGui (MakeKit) поверх `7z.dll` від 7-Zip. Один exe без рантайму; стара C#/WinForms-версія лежить у `legacy/`.

## Формати

- **Створення:** 7z, zip, tar, tar.gz, tar.bz2, tar.xz, gz, bz2, xz, wim; самостійний SFX-архів `.exe` для 7z (модуль `7z.sfx` із 7-Zip 26.03)
- **Розпакування:** усе, що читає `7z.dll` — rar/rar5, iso, cab, arj, lzh, cpio, rpm, deb, dmg, vhd, xar, z, msi, chm, wim, багатотомні `.001` та інші

## Головне вікно

Компонування: меню, великий тулбар, «↑» з адресним рядком, дерево тек (Ctrl+T), список і статусбар із підсумком.

- **Диск і архів в одному вікні.** Без аргументів відкривається остання тека. Enter на архіві відкриває його вміст, а «..» у корені архіву повертає в теку, де він лежить. Архів усередині архіву відкривається так само, і «..» веде назад у батьківський.
- **Колонки.** На диску: Назва / Розмір / Тип / Змінено. В архіві: Назва / Розмір / Стиснуто / Тип / Змінено / CRC32; розмір теки — сума її вмісту.
- **Навігація.** Backspace, Alt+↑ або Ctrl+PgUp — вгору; Alt+← / Alt+→ — історія; Ctrl+\ — корінь; Ctrl+PgDn — відкрити файл як архів. В адресний рядок можна ввести шлях, зокрема `C:\a.zip\тека`.
- **Команди** (диск і архів): Alt+A — додати, Alt+E — розпакувати в…, Alt+W — розпакувати без підтвердження, Alt+T — тест, Alt+V — внутрішній переглядач, Del — у Кошик (Shift+Del — назавжди), F2 — перейменувати, Alt+I — відомості (для звичайних файлів — системні «Властивості»), Alt+Q — конвертувати, Alt+G — звіт, F3 — пошук файлів у теках і всередині архівів.
- **Виділення і буфер.** Num+ / Num− — виділити або зняти виділення за маскою (`*.txt;*.md`), Num* — інвертувати. Ctrl+C / Ctrl+V працюють з Провідником; з архіву файли спершу розпаковуються в temp.
- **Обране.** Ctrl+F додає теку чи архів, Ctrl+1…0 відкривають перші десять записів.
- **Вигляд.** Ctrl+H — плаский список усіх файлів архіву; ще є режими «Список» і «Таблиця». Розмір вікна, дерево, режим і остання тека запам'ятовуються.
- **Тема й іконки.** Темна тема Carbon Mint і набір іконок з MakeKit, іконки вбудовані в exe. PNG у теці `icons\` поруч з exe підміняє будь-яку з них без перезбирання; список — [docs/ICONS-NEEDED.md](docs/ICONS-NEEDED.md).

Перевірки: `zig build test`, `MakePack.exe --selftest`, `tools\bugtest.ps1` (чорна скринька: CLI і вікна через автоматизацію MakeKit, у пісочниці — власні `MAKEPACK_INSTANCE`, `MAKEPACK_SETTINGS`, `MAKEPACK_REGROOT`, тека в `%TEMP%`; справжні мишу й клавіатуру не чіпає, вікна — на моніторі `-Screen`, типово 1), `tools\guismoke.ps1` (знімки головного вікна після натискань), `tools\shots.ps1` (знімки всіх вікон і діалогів для перевірки теми → `zig-out\shots`), `tools\settingstest.ps1` (збереження налаштувань). `tools\dragtest.ps1` рухає справжню мишу — лише вручну. `tools\uiadump.ps1` — UIA-дерево + скріншот будь-якого чужого вікна (ImGui-вікна MakePack UIA не бачить).

## Збірка

```powershell
tools\build.ps1                  # версія 2.0.0
tools\build.ps1 -Version 1.2.3   # своя версія
tools\build.ps1 -NoSign          # пакет меню Windows 11 без підпису (суха збірка, такий пакет не встановиться)
```

Потрібні Zig 0.17.1 у `%LOCALAPPDATA%\Programs\zig\0.17.1\`, сусідня тека `..\MakeKit`, Inno Setup 6 і Windows SDK (`makeappx`, `signtool`; для підпису одноразово `tools\new_cert.ps1`). Python потрібен лише для іконки. Кроки: `zig build -Doptimize=ReleaseSafe` → `dist\app` (MakePack.exe, 7z.dll, 7z.sfx) → `tools\build_shell.ps1` → `dist\shell` → ISCC. Результат: `dist\MakePack-Setup-<версія>.exe`.

## Контекстне меню та асоціації

Інсталятор ставить такі пункти:
- «Розпакувати тут», «Розпакувати в папку\», «Відкрити в MakePack»;
- «Додати в архів (MakePack)…» з діалогом;
- **«Додати в .7z (MakePack)»** — одразу, без діалогу. Архів отримує ім'я файлу чи теки (для кількох вибраних — ім'я їхньої теки) і лягає поруч;
- **Створити → Архів MakePack** у Провіднику — порожній `.7z`, у який можна перетягувати файли. Пункт з'являється, лише поки `.7z` відкривається в MakePack (асоціація).

Будь-який пункт можна вимкнути в діалозі «Асоціації…» (група «Пункти контекстного меню Провідника»). Там само обирається формат для «Додати в …». Вибір діє і на класичне меню, і на меню Windows 11.
У Windows 11 класичні пункти живуть під «Показати додаткові параметри»; у верхньому меню є окремий пункт — див. нижче.

## Контекстне меню Windows 11

Задача інсталятора «Пункт MakePack у контекстному меню Windows 11» (увімкнена за замовчуванням, лише на Windows 11) додає у **верхнє** меню Провідника підменю **MakePack**:

- **Відкрити в MakePack** — один вибраний архів;
- **Розпакувати тут** та **Розпакувати в «назва\»** (для кількох архівів — «Розпакувати кожен в окрему теку») — коли всі вибрані елементи є архівами;
- **Додати в архів…** — для будь-яких файлів і тек;
- **Додати в «назва.7z»** — те саме без діалогу, назва архіву видна прямо в меню.

Технічно це shell-розширення `MakePackShell.dll` (`shell\`), зареєстроване sparse-MSIX пакетом `MakePackShell.msix` із зовнішнім розташуванням у теці програми. Пакет підписано власним сертифікатом `CN=MakeMD`, тож **при першому встановленні Windows один раз попросить права адміністратора (UAC)** — щоб додати `MakePack.cer` до довірених (`TrustedPeople`). Відмовилися — встановлення продовжиться без цього пункту, класичні пункти працюють як і раніше.

Прибрати: зняти прапорець задачі при повторному встановленні або видалити MakePack. Сертифікат лишається в довірених (видалення потребувало б ще одного UAC); прибрати вручну: `certutil -delstore TrustedPeople MakeMD` в адмінському терміналі.

Збірка: `tools\new_cert.ps1` один раз (сертифікат у `shell\cert\`, пароль у `.env`), далі `tools\build.ps1` сам викликає `tools\build_shell.ps1` (DLL на Zig — `shell\shell.zig`, пакет — `makeappx` і `signtool` з Windows SDK). Той самий скрипт проганяє `shell\test\harness.cpp` (`zig build test-shell`) — перевірку меню й командних рядків без встановлення.

Кнопка **«Асоціації…»** в самому додатку відкриває діалог із прапорцем на кожне розширення — як Options→System у 7-Zip. Додаток сам пише реєстр (тільки HKCU, без прав адміністратора), показує поточного власника типу і позначає ті, які Windows або інша програма вже закріпили за собою.

Інсталятор реєструє **лише типові розширення й лише ті, які ще ніхто не зайняв** (7z, rar, tar, gz, bz2, xz, arj, lzh, cpio, 001 тощо). `.zip`, `.iso`, `.cab`, `.jar` залишаються за поточним власником, доки ви самі не поставите прапорець у діалозі. Виняток — «мертві» власники (програму видалили, а ключі реєстру лишилися): такі розширення MakePack забирає одразу, разом із застарілим вибором користувача (`UserChoice`).

Ті самі дії доступні з командного рядка (тихо, без вікон — цим користується інсталятор):

- `MakePack.exe --assoc` — відкрити діалог асоціацій без головного вікна.
- `MakePack.exe --register defaults` — зареєструвати типові розширення (не відбираючи зайняті).
- `MakePack.exe --register 7z,zip,rar` — примусово забрати перелічені розширення собі.
- `MakePack.exe --unregister [7z,zip]` — прибрати все (або лише перелічене).
- `MakePack.exe --addmenu on|off` — пункт «Додати в архів (MakePack)…» у меню файлів і тек.

## Розпакування

Діалог «Розпакувати» вміє:
- **Теки:** зберігати їх або класти все в одну теку.
- **Оновлення:** розпакувати все, лише нові й новіші файли, або лише оновити наявні.
- **Пошкоджені файли:** залишати їх (типово пошкоджений файл видаляється, а не лишається на диску зі сміттям).
- **Архів після розпакування:** залишити, запитати або перемістити в Кошик. Лише коли розпаковано весь архів без помилок; для багатотомного це всі частини.

Вибір запам'ятовується.

## Відомості та звіт

**«Відомості»** показує окреме вікно з даними архіву і кнопкою «Копіювати»:
- формат, метод і словник;
- суцільність і кількість блоків;
- шифрування (вміст / вміст і імена);
- кількість файлів і тек, розпакований і стиснутий розмір, коефіцієнт;
- кількість томів і коментар.

Меню **«Звіт»** зберігає список файлів архіву (шлях, розмір, дата, CRC, метод) з тими самими підсумками як HTML (відкривається в браузері) чи текст (UTF-8 з BOM) або копіює його в буфер обміну.

## Конвертування архівів

Кнопка **«Конвертувати…»** (або `MakePack.exe convert <архіви…>`) перепаковує кілька архівів (rar, zip, tar.gz, усе, що читає MakePack) в обраний формат і рівень. Новий архів зберігається, лише якщо пройшов перевірку і містить стільки ж файлів і байтів, скільки оригінал; інакше він вилучається, а оригінал не змінюється. Опції:
- залишити старий, якщо новий не менший;
- вилучити оригінали в Кошик;
- пропускати зашифровані.

Пароль переноситься на новий архів. Зашифрований архів у формат без пароля (tar тощо) не конвертується, щоб не розкрити дані. Позначка «з Інтернету» теж переходить на новий архів.

## Позначка «з Інтернету» (Mark of the Web)

Якщо архів завантажено з Інтернету (у нього є потік `Zone.Identifier`), розпаковані файли отримують ту саму позначку. Windows попередить перед запуском такої програми, а Office відкриє документ у захищеному режимі. Без цього архів «відмивав» би завантажений exe у «локальний». Типово позначаються програми й скрипти, документи Office і PDF, а також архіви й образи дисків, щоб позначка переходила далі по ланцюжку. У «Налаштуваннях» можна обрати «Усі файли» або «Не переносити». Діє для всіх шляхів розпакування: вікно, меню Провідника, CLI, перетягування й відкриття файлу подвійним кліком.

## Профілі стиснення

У діалозі «Новий архів» кнопка **«Зберегти…»** запам'ятовує всі поточні опції (формат, рівень, метод, словник, томи, SFX, тест, видалення джерел, окремі архіви) під назвою. **Пароль у профіль не потрапляє ніколи.** Профіль, позначений як типовий, підставляється щоразу, коли відкривається діалог. Перейменувати, вилучити, змінити типовий чи **показати профіль у меню Провідника** — у «Налаштуваннях» (або галочкою при збереженні). Профіль «у меню» отримує власний пункт «Додати в «назва.zip» (Профіль)», який створює архів одразу, без діалогу; кілька вибраних файлів дають один архів. Усі такі пункти разом вимикаються в «Асоціаціях…».

- `MakePack.exe a --quick <файли й теки…>` — «Додати в «назва.7z»» з меню: формат з «Асоціацій», без діалогу.
- `MakePack.exe a --profile "Назва" <файли й теки…>` — створити архів за профілем одразу, без діалогу. Кілька викликів, що прийшли протягом 0,4 с (мультивибір в Провіднику), дають один архів.
- `MakePack.exe --settings` — відкрити «Налаштування» без головного вікна.

## Командний рядок для скриптів

Ці команди працюють без вікон: результат іде в stdout, помилки в stderr, процес завершується з кодом виходу класичних архіваторів.

- `MakePack.exe t [-p] <архів>` — перевірити архів.
- `MakePack.exe l [-p] <архів>` — вивести список файлів і підсумки (той самий текст, що й «Звіт»).
- `MakePack.exe a <ключі…> <архів> <файли, теки, маски…>` — створити архів без діалогу. Ключі пишуться перед назвою архіву, і хоча б один обов'язковий (без ключів відкривається звичайний діалог):
  - `-t7z|zip|tar|tar.gz|tar.bz2|tar.xz|gz|bz2|xz|wim` — формат; без ключа він береться з розширення, а якщо його немає, то 7z;
  - `-m0`…`-m5` — рівень стиснення, від «без стиснення» до «максимальний»;
  - `-v100m` — томи заданого розміру;
  - `-p` — задати пароль; `-hp` — задати пароль і зашифрувати імена файлів (лише 7z);
  - `-y` — перезаписати наявний архів (без цього ключа команда завершується з помилкою).
- `MakePack.exe x -y [-p] <архів> [-o <тека> | --sub]` — розпакувати тихо, з перезаписом. Без `-o` архів розпаковується поруч із собою.

**Пароль ніколи не передається аргументом**, бо його було б видно в історії команд і в списку процесів. Тому `-pСекрет` відхиляється з кодом 7. Пароль береться зі змінної оточення `MAKEPACK_PASSWORD`, а якщо її немає, то `-p` відкриває вікно запиту. Для створення архіву змінна діє лише разом із `-p`/`-hp`, щоб забута змінна не зашифрувала архів випадково.

| Код | Значення |
|---|---|
| 0 | Успіх |
| 1 | Попередження: частину файлів пропущено (наприклад, небезпечні шляхи `..\`) |
| 2 | Фатальна помилка: не архів, архів уже існує, помилка запису |
| 3 | Архів пошкоджений, помилка CRC |
| 7 | Неправильний ключ або пароль в аргументах |
| 10 | Немає файлів: архів не знайдено або маска нічого не знайшла |
| 11 | Потрібен пароль, або пароль неправильний |
| 255 | Скасовано користувачем (Ctrl+C, «Скасувати» у вікні запиту) |

Ті самі коди повертає звичайне `x` з меню Провідника. MakePack — віконна програма, тож щоб дочекатися коду, використовуйте `start /wait MakePack.exe t a.7z` у cmd. У PowerShell достатньо передати вивід далі (`MakePack.exe t a.7z | Out-Host`) і потім прочитати `$LASTEXITCODE`.
