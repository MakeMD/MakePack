# Іконки MakePack

Усі іконки вже вбудовані в exe: це набір Carbon Mint з MakeKit (`kit.icons`, майстри 128 px у `MakeKit\icons\*.png`).
Кожну іконку можна підмінити без перезбірки: поклади PNG у теку `icons\` поруч з `MakePack.exe` під назвою з колонки «Файл».
Файл має пріоритет над вбудованою іконкою.

**Формат підміни:** квадратний PNG з прозорістю, будь-якого розміру. Кит сам масштабує його до потрібного розміру з урахуванням DPI (краще давати 128×128).
**Стиль:** Carbon Mint. Фон антрацитовий `#2D3436`, акцент м'ятний `#00FFC2`.

| `ok.png` | Перевірити | диск, архів |
| `view.png` | Переглянути | диск, архів |

| `info.png` | Відомості | диск, архів |
| `refresh.png` | Конвертувати | диск, архів |
| `report.png` | Звіт | архів |

## Навігація, статусбар, меню, повідомлення (16 px; у повідомленнях 32 px)

| Файл | Де |
|---|---|
| `up.png` | кнопка «Вгору» біля адресного рядка |
| `drive.png` | ліва секція статусбару |
| `lock.png` | ліва секція статусбару, коли архів зашифрований |
| `favorite.png` | меню «Обране» → «Додати» |
| `info.png` | повідомлення «інфо» і «питання» |
| `warning.png` | повідомлення «попередження» |
| `danger.png` | повідомлення «помилка» і підтвердження незворотного вилучення |

## Список і дерево (16 px)

| Файл | Де |
|---|---|
| `folder.png` | теки й рядок «..» |
| `pack.png` | архіви (за розширенням) і корінь дерева архіву |
| `archive_locked.png` | корінь дерева зашифрованого архіву |
| `document.png` | решта файлів |
| `drive.png` | диски в дереві й у списку адрес |

Іконки оболонки Windows (`SHGetFileInfo`) свідомо не беремо: вони кольорові й випадають з палітри.
Іконка застосунку — `icon\makepack.ico` (і логотипи пакета меню Win11 у `shell\package\Assets`), збирається `MakeKit\tools\app_icons.py` з рендеру в `MakeKit\icon-kit\app`.
