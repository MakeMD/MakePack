# Іконки, які треба намалювати для MakePack

Поки що замість них стоять стокові іконки Windows (`SHGetStockIconInfo`, номер SIID у таблиці).
Щоб підмінити іконку, поклади PNG у теку `icons\` поруч з `MakePack.exe` під назвою з колонки «Файл».
Перезбирати нічого не треба: `Icons.Get` спершу шукає файл і лише потім бере стокову.

**Формат:** PNG з прозорістю, квадрат. Для тулбара — **32×32** (на 150 % DPI WinForms масштабує сам; якщо хочеш чіткіше, дай 48×48 — буде зменшено). Для статусбару й меню — **16×16**.
**Стиль:** у тон іконки застосунку (`icon\makepack.svg`: індиго→фіолет + бурштиновий акцент). Тулбар OtherArc — кольорові «предметні» іконки, читаються без підпису.

## Тулбар (32×32)

| Файл | Кнопка | Що зображає | Режим | Зараз (SIID) |
|---|---|---|---|---|
| `add.png` | Додати | файли падають у коробку/архів | диск, архів | 105 zip-тека |
| `extract.png` | Розпакувати в… | з коробки виходить тека | диск, архів | 45 тека зі стрілкою |
| `test.png` | Перевірити | архів + галочка/щит | диск, архів | 77 щит |
| `view.png` | Переглянути | документ/лупа над текстом | диск, архів | 1 документ |
| `delete.png` | Вилучити | кошик | диск, архів | 31 кошик |
| `find.png` | Знайти | лупа | диск, архів | 22 лупа |
| `info.png` | Відомості | «i» в колі | диск, архів | 79 інфо |
| `convert.png` | Конвертувати | дві коробки зі стрілками між ними | диск, архів | 46 стрілки синхронізації |
| `report.png` | Звіт | аркуш зі списком | архів | 39 список |

## Навігація і статусбар (16×16)

| Файл | Де | Що зображає | Зараз |
|---|---|---|---|
| `up.png` | кнопка «Вгору» біля адресного рядка | стрілка вгору (сіра,) | текст «↑» |
| `drive.png` | ліва секція статусбару | диск | SIID 8 |
| `lock.png` | ліва секція статусбару, коли архів зашифрований | замок | SIID 47 |
| `favorite.png` | меню «Обране» → «Додати» | зірка | SIID 43 |

## Не потрібні

Іконки файлів у списку й дереві беруться з оболонки Windows (`SHGetFileInfo`), тому для `.zip`, `.7z` тощо діють іконки асоціацій. Іконка застосунку вже є (`icon\makepack.svg`).
